# Roadmap

## MVP requirements

- [x] Separate application/repository from AssetStudio
- [x] FBX import architecture
- [x] Parts and animation model
- [x] Visibility profile JSON format
- [ ] OpenGL renderer
- [ ] CPU skinning playback
- [ ] part picking/highlight
- [ ] MP4/WebP export
- [ ] optional filtered FBX export

## Non-goals

- modeling
- sculpting
- mesh editing
- rig authoring
- material authoring
- replacing Blender

The program is an animation/visibility inspector and renderer.
